Service website / Live website

VW Plus

From a warning light to a useful workshop enquiry

Visit the website ↗

Designed across screens

The same customer journey, composed for desktop and mobile. These are actual website captures from 1 October 2026.

01 Context

A responsive automotive website that helps drivers describe a problem, explore specialist services and start a more informed workshop conversation.

02 Problem

Drivers need a clear first step, whether they have a symptom, a service need or a restoration project.

03 Idea / Thinking

Organise the journey around the car and the owner’s immediate need, then make workshop evidence easy to explore.

04 My Role

Content strategy, customer-journey design, visual direction and AI-assisted website development.

05 What I Built / Did

Vehicle selection, troubleshooting pathways, service pages, structured enquiries and a workshop case archive, including a documented Jetta repair journey.

06 Output

A live customer-facing website, designed for mobile use as well as desktop.

07 Evidence

The public site provides the service, troubleshooting and enquiry journeys. The separate customer-dashboard concept uses sample data and remains a prototype.

08 Status

Published website.

09 Learning / Next question

How can the next iteration make the enquiry journey clearer?
